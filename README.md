# BeenBlock

BeenBlock — Android-приложение для блокировки выбранных **не-системных** приложений (кроме самого BeenBlock). Когда пользователь пытается открыть заблокированное приложение, служба специальных возможностей мгновенно возвращает его на главный экран.

## Возможности

- Выбор приложений для блокировки (не-системные, без BeenBlock).
- Блокировка через **AccessibilityService** — работает в фоне, даже если BeenBlock закрыт (при включённой службе).
- UI в стиле **Material 3 + Liquid Glass** с плавными анимациями.
- Проверка статуса службы и оптимизации батареи с переходом в системные настройки.
- Сборка через **GitHub Actions**.

## Как использовать

1. Установите APK и откройте BeenBlock.
2. Выберите приложения, которые нужно заблокировать.
3. Включите **BeenBlock** в настройках специальных возможностей.
4. (Рекомендуется) отключите ограничения оптимизации батареи для BeenBlock.
5. Закройте BeenBlock — блокировка продолжит работать в фоне.

## Важно

- Надёжность фоновой работы зависит от OEM/версии Android. На некоторых устройствах может потребоваться вручную разрешить автозапуск/фон.
- Разрешение `QUERY_ALL_PACKAGES` используется для отображения установленных приложений. Для публикации в Google Play требуется соблюдать политику использования этого разрешения.
- Приложение не собирает и не передаёт данные пользователей.

## Сборка

Требования: JDK 17, Android SDK (compile/target 35), Gradle 8.9+.

```bash
cd BeenBlock
gradle wrapper --gradle-version 8.9   # при необходимости
./gradlew :app:assembleDebug
```

APK: `BeenBlock/app/build/outputs/apk/debug/app-debug.apk`.

## GitHub Actions

Workflow: `.github/workflows/android.yml`  
Собирает debug APK на `push`/`pull_request`/ручном запуске и публикует артефакт `BeenBlock-debug-apk`.

## Стек
